# Proximos passos

## Fase 0: Fundacao

- Definir escopo do MVP.
- Definir arquitetura inicial.
- Definir regras de seguranca e moderacao.
- Definir telas essenciais.

## Fase 1: Prototipo navegavel

- Criar projeto Next.js.
- Criar identidade visual simples.
- Criar paginas principais.
- Criar formulario de familia.
- Criar formulario de anfitriao.
- Criar painel admin inicial com dados simulados.

## Fase 2: Banco e autenticacao

- Criar projeto no Supabase.
- Modelar tabelas.
- Configurar login.
- Configurar permissoes.
- Conectar formularios ao banco.

## Fase 3: Operacao piloto

- Testar com poucas pessoas.
- Ajustar perguntas dos formularios.
- Criar processo manual de verificacao.
- Preparar termos e politica de privacidade.

## Fase 4: Publicacao inicial

- Publicar web app na Vercel.
- Configurar dominio.
- Preparar pagina institucional.
- Abrir inscricoes de familias e anfitrioes.

## Fase 5: App mobile

- Avaliar uso real.
- Transformar em PWA ou app Expo.
- Preparar publicacao na Google Play.
- Preparar publicacao na App Store.
